# Bine Store — сайт магазина

Многостраничный сайт без сборки: обычные HTML/CSS/JS. Его можно выложить на любой статический хостинг: Firebase Hosting, Netlify, Vercel, GitHub Pages.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная |
| `catalog.html` | Каталог: фильтры, поиск, сортировка |
| `product.html?id=…` | Карточка товара: галерея, размеры |
| `checkout.html` | Оформление заказа |
| `account.html` | Вход, регистрация и личный кабинет (заказы, избранное, профиль) |
| `admin.html` | Админ-панель: товары, фото, заказы |
| `china.html` | Заявка «под заказ из Китая» |
| `delivery.html` | Доставка и оплата |
| `privacy.html`, `terms.html`, `returns.html`, `cookies.html` | Юридические документы |
| `404.html` | Страница «не найдено» |

## 1. Контакты и реквизиты

Откройте `js/config.js`:
- в блоке `SHOP` впишите свои Telegram, WhatsApp, Viber и Instagram;
- в блоке `COMPANY` укажите название продавца (ÎI / SRL), IDNO, адрес, email и телефон. Пока поля пустые, в документах они подсвечены жёлтым.

Юридические тексты — это шаблон под Молдову (законы № 133/2011 и № 105/2003). Перед запуском покажите их юристу.

## 2. Демо-режим

Пока Firebase не подключён, сайт работает в **демо-режиме**: товары, заказы и аккаунты хранятся только в вашем браузере. Это удобно, чтобы всё проверить, но покупатели ваших товаров не увидят.

Вход в админку в демо-режиме — данные `DEMO_ADMIN` в `js/config.js`.

## 3. Подключение Firebase (бесплатно)

1. Откройте https://console.firebase.google.com и создайте проект.
2. **Build → Authentication → Get started → Email/Password → Enable.**
3. **Build → Firestore Database → Create database** (production mode, регион `eur3`).
4. **Firestore → Rules:** вставьте содержимое файла `firestore.rules` и нажмите **Publish**.
5. **Project settings → Your apps → Web (`</>`)**: зарегистрируйте приложение и скопируйте `firebaseConfig` в блок `FIREBASE` файла `js/config.js`.
6. **Authentication → Settings → Authorized domains:** добавьте домен своего сайта.

### Как сделать себя администратором

1. Зарегистрируйтесь на сайте (`account.html`).
2. В консоли откройте **Authentication → Users** и скопируйте свой **User UID**.
3. **Firestore → Start collection**, ID коллекции — `admins`, ID документа — ваш UID. Добавьте любое поле, например `role` = `owner`.
4. Обновите сайт: в кабинете появится ссылка «Админ-панель».

В админке есть кнопка «Загрузить демо-товары», если нужно быстро наполнить каталог.

## Фото товаров

Фото загружаются в админке: перетащите файлы или нажмите на область загрузки. Сайт сам сжимает их до ~1400 px в WebP и хранит в Firestore, поэтому платный Cloud Storage не нужен. Первое фото — обложка, второе показывается при наведении на карточку. Порядок меняется перетаскиванием.

## Публикация

Загрузите все файлы, кроме папки `.claude`. Для Firebase Hosting:

```bash
npm i -g firebase-tools
firebase login
firebase init hosting
firebase deploy
```

После правок CSS/JS увеличьте `?v=7` в HTML-файлах, чтобы у посетителей обновился кэш.

## Заставка

Видео `assets/intro.webm` показывается один раз за визит. Чтобы заменить его, положите новый файл с тем же именем.

## Лицензии

- Шрифты Dela Gothic One и Onest — Google Fonts, лицензия SIL Open Font License: коммерческое использование разрешено.
- Фото товаров загружайте только свои или те, на которые у вас есть права. Официальные фото брендов и маркетплейсов без разрешения использовать нельзя.
- Названия брендов — товарные знаки их владельцев; дисклеймер уже есть в подвале и в условиях.

## CRM

CRM — отдельный сайт в своём репозитории (папка `D:\BINECRM`). Он подключается к тому же проекту Firebase, поэтому заказы и заявки с этого сайта сами появляются в CRM. Остатки, которые ведутся в CRM, отключают на сайте закончившиеся размеры. Правила `firestore.rules` общие для обоих сайтов.
